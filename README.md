# Instagram Username Finder

A Python script to find available Instagram usernames (4-5 characters) by guessing. 
It uses rate limiting and proxy rotation to avoid detection.

## Features
- **Random Guessing**: Generates usernames with 4-5 characters (letters + numbers).
- **Human-like Behavior**: Uses random delays and rotating User-Agents.
- **Proxy Support**: Supports rotating proxies to avoid IP bans.
- **Auto-Stop**: Stops immediately when an available username is found.

## Installation

## Usage

### 1. Prepare Proxies (Optional but Recommended)

If you have a list of proxies, save them in `proxies.txt` in the following format:
```text
http://ip:port
http://user:pass@ip:port
Then, test which proxies are valid:

Copy
python test_proxies.py
This will generate a valid_proxies.txt file containing only the working proxies.

2. Run the Finder
To run the script with valid proxies:

Copy
python find_username.py
To run without proxies (direct connection):
Edit find_username.py and change:

Copy
finder = InstagramUsernameFinder(proxy_file="valid_proxies.txt")
to:

Copy
finder = InstagramUsernameFinder()
How It Works
The script generates a random 4-5 character username.
It queries Instagram's internal search API (/web/search/topsearch/).
If the username appears in the search results, it is considered taken.
If it does not appear, it is considered available.
The script stops as soon as an available username is found.

Notes
Accuracy: The search API may show similar usernames, so results are not 100% accurate. For 100% verification, visit https://www.instagram.com/{username}/ manually.
Rate Limiting: If Instagram detects bot-like behavior, it may return a 429 error. The script handles this by waiting 30 seconds.
Proxies: Using proxies is highly recommended if you plan to run many searches to avoid IP blocking.
